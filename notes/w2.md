# Notes: Form W-2 statistics (`national/w2/`)

Documentation compiled 2026-08-17, verified against the local files and an
HTTP probe of TY2015–2024. Source: [SOI Tax Stats — Individual information
return Form W-2 statistics][w2].

[w2]: https://www.irs.gov/statistics/soi-tax-stats-individual-information-return-form-w2-statistics

## What they are

Four tables built from **Form W-2** information returns matched to individual
returns — the only SOI individual series that resolves **wages at the earner
level** (rather than the return level) and carries the elective-deferral and
retirement-plan-indicator boxes. Money amounts are **thousands of dollars**.

## Coverage: TY2019 and TY2020 only

Eight files, `{yy}in0{n}w2all.xlsx`, tables 1–4 for TY2019 and TY2020.
**TY2021–2024 were probed in both `.xlsx` and `.xls` and are absent**, as are
TY2015–2018. Treat the series as stalled, not merely late: it has published
nothing for four tax years. The downloader still generates targets for later
years, so a new vintage is picked up automatically if SOI resumes.

| Repo file | Table | Contents |
|---|---|---|
| `w2_t1_{year}.xlsx` | 1 | Taxpayers with wage income, by age and sex, size of wage income, share of total wages, size of AGI, return/earner type, and multiple of the OASDI taxable-wage limit |
| `w2_t2_{year}.xlsx` | 2 | Taxpayers with **elective retirement contributions**, incl. high/low earners on joint returns, those at the maximum contribution, and size of contribution |
| `w2_t3_{year}.xlsx` | 3 | Taxpayers with and without the **retirement plan indicator**, by size of wages, size of AGI, age, return/earner type and sex |
| `w2_t4_{year}.xlsx` | 4 | Joint returns with two wage earners, by spousal presence of contributions and/or the plan indicator, percentiles, and plan type |

## Parsing gotchas

- **Each file is a multi-sheet workbook, one sheet per cross-tab**, and the
  sheet count differs by table: Table 1 has 8 (`Table 1.A` … `1.H`), Table 2
  has 13 (`2.A` … `2.M`), Table 3 has 5, Table 4 has 4. The file-level title
  names only the first sheet, so anything that reads sheet 1 and stops will
  silently take one cross-tab and miss the rest — iterate `excel_sheets()`.
- Sheet names are the stable key (`Table 2.J`), not the sheet order.

## Known consumers

None yet. The two natural uses: as the earner-level counterpart to the
return-level wage lines in Pub 1304 Table 1.4, and as the cross-check target
for the Form W-2 boxes in Pub 5385 (whose TY2019–2020 overlap with this
series is exact) — see [expansion_plan.md](expansion_plan.md).
