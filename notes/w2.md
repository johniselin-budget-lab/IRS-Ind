# Notes: Form W-2 statistics (`national/w2/`)

Compiled 2026-08-17, **corrected 2026-09-09** after four earlier vintages
turned up that the first survey missed (see "How the earlier files were
missed"). Verified against the local files and an HTTP probe of five stub
shapes × TY1995–2024. Source: [SOI Tax Stats — Individual information return
Form W-2 statistics][w2].

[w2]: https://www.irs.gov/statistics/soi-tax-stats-individual-information-return-form-w2-statistics

## What they are

Tables built from **Form W-2** information returns matched to individual
income tax returns — the only SOI individual series that resolves **wages at
the earner level** rather than the return level, and the only one carrying the
elective-deferral and retirement-plan-indicator boxes. Money amounts are
**thousands of dollars**.

## Coverage: TY2014–2020, in two shapes, with TY2015 missing

| Tax years | Stub | Shape |
|---|---|---|
| 2014, 2016, 2017, 2018 | `{yy}inallw2.xls` | **one** workbook, 51 sheets, Tables **1–7** |
| 2019, 2020 | `{yy}in0{n}w2all.xlsx` | **four** workbooks, 30 sheets, Tables **1–4** |

- **TY2015 does not exist** under either stub, nor under three other shapes
  probed (`{yy}allw2`, `{yy}inw2all`, `{yy}w2all`), in `.xls` or `.xlsx`.
- **Nothing has published since TY2020** (TY2021–2024 probed, absent). Treat
  the series as stalled rather than late. The downloader still generates
  targets for later years, so a resumed vintage is picked up automatically.

**The older format is the richer one.** Going from TY2018 to TY2019 the
program lost three whole tables and all of its age stratification:

| | TY2014–2018 | TY2019–2020 |
|---|---|---|
| Tables | 1–7 | 1–4 |
| Sheets | 51 | 30 |
| Age-stratified sub-sheets | `1.F.1`–`1.F.6`, `3.A.1`–`3.A.6`, `3.E.1`–`3.E.6` (wage and plan-indicator tables cut into six age bands) | none |
| Table 4 | `4.A` only | `4.A`–`4.D` |

Tables 5–7, present only through TY2018, are: **5.A** summary of Form W-2
items by return and earner type; **6.A** values of selected items by
percentile; **7.A** elective retirement contributions by contribution plan
type. Some of that content appears to have been folded into the later Table 4
(`4.A`–`4.D` covers percentiles and plan type), but the mapping has not been
verified line by line — check before treating any of it as one series.

### Table map

| Table | Contents |
|---|---|
| 1 | Wage income by age and sex, size of wage income, share of total wages, size of AGI, return/earner type, and multiples of the OASDI taxable-wage limit |
| 2 | **Elective retirement contributions**, incl. high/low earners on joint returns, taxpayers at the maximum, and size of contribution |
| 3 | Taxpayers with and without the **retirement plan indicator**, by size of wages, size of AGI, age, return/earner type and sex |
| 4 | Joint returns with two wage earners, by spousal presence of contributions and/or the plan indicator |
| 5–7 | *(TY2014–2018 only)* summary of items; values by percentile; contributions by plan type |

## How the earlier files were missed

Worth recording, because the failure generalises. The first survey swept the
modern stub thoroughly — every table number, every year TY2015–2024, both
extensions — and concluded "TY2019–2020 only". It could not have found the
earlier files, because **the word order flips**: `inallw2` versus `in0{n}w2all`.
A probe sweep tests variations of one guessed shape; it says nothing about a
differently-shaped name.

The source page is no help either: it links **only TY2019 and TY2020**. The
four earlier workbooks are live on the server but unlisted anywhere on it, so
neither scraping the page nor probing the modern stub would surface them.

Practical rule for the next family: probe *shapes*, not just parameters, and
treat "the page lists N years" as a lower bound on what exists — the IRA
family in this repo has three separate instances of the same thing
([ira.md](ira.md)).

## Parsing gotchas

- **Every file is a multi-sheet workbook, one sheet per cross-tab**, and the
  count varies: TY2019–2020 Table 1 has 8 sheets (`Table 1.A` … `1.H`), Table
  2 has 13, Table 3 has 5, Table 4 has 4; the TY2014–2018 workbook has 51.
  Anything that reads sheet 1 and stops silently takes one cross-tab out of
  many — iterate `excel_sheets()`.
- **Sheet names are the stable key** (`Table 2.J`), not sheet order.
- The TY2014–2018 workbook opens with a **`Contents` sheet** listing every
  table under four headings (Summary, Wage, Elective Retirement Contribution,
  Retirement Plan Indicator statistics). Read it rather than inferring the
  layout — it is how the Tables 5–7 above were identified.
- All files are ordinary OLE2 `.xls`/`.xlsx`; none are the legacy BIFF4 that
  defeats `readxl` elsewhere in this store (see [ira.md](ira.md),
  [sole_prop.md](sole_prop.md)).

## Known consumers

None yet. Two natural uses: as the earner-level counterpart to the
return-level wage lines in Pub 1304 Table 1.4, and as the cross-check target
for the Form W-2 boxes in Pub 5385, whose TY2019–2020 overlap with this series
is exact — see [expansion_plan.md](expansion_plan.md).
